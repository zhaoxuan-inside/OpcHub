## 1. 规约总则与法定治理原则

OpcHub 定位于为**超级个体 / 一人公司（OPC）**提供政策匹配、算力基建优惠、合规文书生成、产品展示与需求撮合的综合数字化底座。
平台涉及海量用户生成内容（UGC）、企业级商业外包、政府政务数据检索与跨境资金结算，必须构筑坚不可摧的法律安全防线，杜绝任何行政处罚、侵权诉讼与刑事合规风险。

### 核心合规铁律：
1. **源头公开合法原则**：仅采集各级人民政府及职能部门**公开挂网**的政务公文，绝不碰任何第三方商业政策数据库，绝不碰任何涉密/内部公文。
2. **温和礼貌抓取原则**：爬虫技术严格限速控频、错峰运行，严禁高并发挤占政务网站带宽，严禁逆向破解任何政务防护机制。
3. **后台实名、前台自愿**：严格落实《网络安全法》第24条，发帖/评论/交易强制绑定有效手机号，前台强制公开 IP 属地。
4. **内容治理先审与快处**：敏感词本地 Trie 树前置拦截，一键全网下架与证据留存并举，网络日志依法保留至少 180 天。
5. **资金防二清与自营脱钩**：需求集市与履约交易严禁平台设立资金池，全链路对接持牌第三方支付机构分账托管。
6. **免责与知情强授权**：所有政策结果、章程文书明确“不构成法定法律意见与行政审批背书”，协议拒绝默认勾选。

## 2. 政府政策信息采集红线与合规爬虫规范 (Policy Scraping Spec)

### 2.1 法律定性与版权边界
- **法律依据**：《中华人民共和国著作权法》第五条第一项明确规定：**法律、法规，国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件，及其官方正式译文，不受著作权法保护。**
- **合规边界**：
  - ✅ **合法采集对象**：国务院、各部委、各省/市/区县人民政府门户网站公开发布的政策公文、补贴通知、申报指南原文。
  - ❌ **严禁侵权对象**：坚决不得采集任何**第三方商业政策聚合平台**（如商业企策通、企查查政策库等）。第三方平台的分类标签体系、独家解读、申报条件结构化加工属于其**汇编作品与商业数据财产**，批量抓取构成著作权侵权并触犯《反不正当竞争法》第二条。

### 2.2 刑事风险红线与避坑规范
- **红线一：禁止危害计算机信息系统安全（《刑法》第286条）**
  - **规约**：单 IP 请求频率严格限制为 **$\ge 2$ 秒/次**；单站点并发连接数上限为 **1**；
  - **执行**：采集任务必须配置在**凌晨低峰期（01:00 ~ 05:00）**运行，严禁在白天政务工作时段高频调度。
- **红线二：禁止非法侵入与非法获取数据（《刑法》第285条）**
  - **规约**：严禁使用打码平台破解图形验证码、滑块验证码；严禁逆向分析政务 WAF 防护与 JS 加密签名参数；
  - **执行**：凡遇到需要登录、验证码拦截的政务页面，立即跳过并告警，转由人工录入或官方开放接口获取。
- **红线三：严禁采集涉密与非公开公文（保密法与刑法涉密罪）**
  - **规约**：爬虫解析引擎内置涉密敏感词过滤器；
  - **执行**：凡标题或正文包含 `涉密`、`内部商榷`、`征求意见稿`、`密级`、`请勿外传`、`内部流转` 等字样的文档，引擎立即丢弃并记录黑名单，绝不入库展示。

### 2.3 政策信息展示与免责规约 (Product Attribution Spec)
平台前台展示政策条目时，必须严格执行三要素：
1. **官方出处与原文溯源**：
   - 每条政策卡片强制展示发文部门（如：`杭州市科学技术局`）与发文字号；
   - 必须提供 `查看官方原件` 外链，直通政府官方门户网站，增强公信力并规避断章取义风险。
2. **时效性与生命周期明确标注**：
   - 标注 `发布日期`、`申报起止日期`、`有效年限`；
   - 针对已到期或废止政策，强制渲染灰色 `已截止` 标签，禁止推荐申报。
3. **醒目免责声明**：
   - 政策详情页与匹配结果页常驻免责提示：
     > *“本平台政策信息均摘录自各级人民政府官方公开渠道，AI 提炼仅供参考。申报资格、申报材料与资金划拨请以主管政府部门最新正式发文为准，平台不承担因政策调整导致的申报损失。”*
4. **禁止冒充政府官方**：
   - 界面严禁使用国徽、政府公权力标志；严禁使用“官方指定申报渠道”、“包过保拿补贴”等虚假违规宣传话术。

## 3. UGC 社区与内容安全防线规约 (Content Moderation Spec)

### 3.1 敏感词检测与前置拦截引擎
- **拦截词库分类**：
  1. **政治与法律红线**：涉政、暴恐、危害国家安全言论；
  2. **商业秘密与机密泄露**：非法倒卖内网 API Key、未脱敏用户数据、侵入式黑产工具；
  3. **虚假财税与金融黑产**：虚开发票、假报税、地下钱庄、USDT 变现洗钱引流；
  4. **垃圾灌水与恶意刷量**：批量外挂脚本、引流联系方式（微信号变体、暗码）。
- **执行机制**：
  - 前置发帖与评论提交时，调用微内核敏感词校验算子；
  - 命中一级违规词：**直接阻断提交**并弹出温和提示（“内容包含不符合社区规范的词汇，请修改后重试”）；
  - 命中疑似二级风险词：**异步进入人工复核队列**，暂缓前台大盘推荐。

### 3.2 群众监督与一键举报闭环
- **前台入口**：创客头脑风暴所有主帖、楼中楼评论、产品评价及需求卡片，均挂载专属微图标 `举报言论` 入口；
- **举报流转**：用户选择举报理由（涉嫌违法、泄露秘密、涉税欺诈、垃圾营销等）后，事件毫秒级同步推送至管理端 **View 12 内容治理控制台**。

### 3.3 言论下架与防篡改存证（状态留痕）
- **严禁物理硬删除**：下架违规言论时，后端执行 `status = TAKEN_DOWN`，记录操作人、下架原因与时间戳；
- **网络日志依法留存**：系统访问日志、发帖时间、操作 IP 必须在数据库或归档系统中**加密保存至少 180 天（6个月）**，以备公安与网信部门调证。

## 4. 真实身份认证与账号合规规约 (Account & Identity Spec)

### 4.1 “后台实名、前台自愿”
- **发帖与交易前置实名**：
  - 创客在发布讨论帖、发表回答、发布产品或提交需求前，账户必须通过**手机号短信验证码**核验；
  - 涉及企业认证与需求竞标的企业，需核验统一社会信用代码与法定代表人身份。

### 4.2 发帖 IP 属地强制公开
- 遵守《互联网用户账号信息管理规定》第12条：
  - 头脑风暴帖子、多级回答、商品评价等位置，**强制展示发帖人 IP 属地**（境内展示至省份/直辖市，如“来自 浙江”；境外展示至国家或地区）；
  - 该属性由服务端依据客户端请求 IP 解析，用户不可在个人中心手动修改或关闭。

### 4.3 账号注销与数据遗忘权通道
- 用户中心（View 10）必须提供清晰合法的**注销账号**通道；
- 申请注销后提供合理的冷静期（或即时安全注销），注销完成后依法对用户手机号、身份证件等个人信息进行**不可逆脱敏或物理销毁**。

## 5. 法律协议矩阵与知情授权标准 (Legal Agreement Matrix)

### 5.1 协议体系架构
平台依法构建完备的六维法律协议矩阵：

| 协议名称 | 核心法律目的与约束场景 | 强制触发节点 |
| :--- | :--- | :--- |
| **《用户服务协议》** | 界定平台与创客基础民事权利义务、账号使用权归属、违规封禁条款 | 用户首次注册/登录 |
| **《隐私政策》** | 明示收集个人信息清单、使用目的、存储期限、第三方 SDK 共享清单 | 用户首次注册/登录 |
| **《创客社区自律公约》** | 规范头脑风暴社区讨论与技术分享行为，严禁泄露商业机密与发布灰黑产外挂 | 首次发帖/发表评论 |
| **《商户入驻与需求撮合协议》** | 明确产品橱窗展示规范、需求集市竞标规则与交易纠纷处理规则 | 申请发布产品/需求竞标 |
| **《SOP 文书免责声明》** | 声明平台自动生成的《企业章程》、《合作协议》仅供参考，非执业律师意见 | 进入流程文书生成器 |
| **《算法推荐说明与关闭指引》** | 履行算法推荐备案告知义务，提供关闭个性化推荐的机制 | 隐私政策中常驻说明 |

### 5.2 授权交互红线
- ❌ **严禁默认勾选**：用户注册登录弹窗中的“我已阅读并同意《隐私政策》”单选框，**初始状态必须为空白未勾选**，必须由用户自主点击勾选；
- ❌ **严禁静默更新**：当隐私政策有实质性条款变更时，用户下一次打开应用必须弹出强提示确认窗。

## 6. 交易履约与财税金融合规规约 (FinTech Compliance Spec)

### 6.1 坚决杜绝“资金二清”
- **红线规定**：根据中国人民银行关于无证经营支付业务的整治要求，**OpcHub 平台本身绝不设立任何自有沉淀资金池**。
- **架构方案**：
  - 创客在需求集市中的技术报酬、竞标保证金，全流程通过**持牌第三方支付机构**（微信支付商户分账、支付宝商户托管、PingPong/Stripe 跨境资金结算通道）完成代收代付与资金冻结解冻；
  - 平台仅充当指令发起与线索撮合方，不经手创客资金流水。

### 6.2 纳税申报与虚开发票风险隔离
- 需求集市中明确提示创客依法纳税义务，提醒个体工商户按期进行经营所得汇算清缴；
- 平台严禁创客发布“代买发票”、“冲抵成本虚开发票”的任何线索与服务商广告，一经发现一票否决封号并移送税务线索。
